# ProgressRail

Keep ordered process stages readable beside wider log or evidence panels. Each
stage has a 19px status node, a label to its right and optional detail beneath.
A thin connector joins adjacent stages. The rail fills the width its parent gives
it; this example uses 140px. Labels and detail wrap within that width.

## Reported state

The caller supplies every stage and its state. Completed stages show a green
check, the current stage an accent dot, pending stages a neutral outline, and
an error stage a red cross. Completion describes this process stage, not an
aggregate evaluation verdict. A finished job can still contain failed tests.

Use at most one `current` or `error` stage for a single process; both mark the
current step with `aria-current="step"`. State is also provided as accessible text,
so color is not the only signal. The ordered list has a required accessible name.
No stages render when `items` is empty.

## Host-owned content

`detail` can contain an observed timestamp, duration or short status. ProgressRail
does not infer times, poll jobs, animate progress or add controls. Keep labels and
detail passive; put retry or authorization actions in the surrounding panel.
Stable unique IDs preserve each stage's identity when its state changes.

| Prop         | Type                          | Purpose                                                                           |
| ------------ | ----------------------------- | --------------------------------------------------------------------------------- |
| `items`      | `readonly ProgressRailItem[]` | Ordered stages with unique `id`, `label`, optional `detail` and explicit `state`. |
| `aria-label` | `string`                      | Required accessible name for the ordered list.                                    |
| `className`  | `string`                      | Additional classes on the list; width belongs to the parent.                      |

`ProgressRailItem.state` is `complete`, `current`, `pending` or `error`.
`label` and `detail` accept React nodes. The component does not render navigation,
buttons, an independent scroll area or a live region.
