# Elevation & depth

Four shadow tints layered onto the panel surface. Light mode uses ink-tinted black at
low opacity; dark mode uses pure black at higher opacity (the same custom property
tracks both themes).

## Shadow scale

`tint-1` is the resting panel base; `tint-2` lifts a popover off the page; `tint-3`
floats a modal or vim-help overlay. The inset variant marks pressed states and focused
inputs.

## Z-index layers

A small fixed set of layers — never invent ad-hoc z-indices.

| Layer | z-index | What sits there |
|---|---|---|
| Page content | `0` (auto) | Body, prose, specimens — the default plane |
| Sticky in-page chrome | `[3]` | Sticky `<H2>` headings inside the prose |
| Search backdrop | `40` | Dim/blur layer behind the cmd+K palette when open |
| Search panel | `[49]` | The cmd+K results card surface |
| Page chrome (topbar) | `50` | The sticky doc topbar |
| Search input (open) | `[71]` | The search input portals out of the topbar when the palette is open, sitting above every other layer so it's the only thing receiving keystrokes |

Component-internal stacking (the `ThemeToggle` puck, the `ZebraRunSpecimen`
selection ring) uses small ints (`z-0` / `z-10` / `z-[1]` / `z-[2]`) inside its own
`isolate` boundary. Those don't compose with the page ladder above — they're private to
the component.

## Collection preview depth

Use [PreviewStack](/components/preview-stack/) when covers represent the contents
of a collection. Keep the representative front cover sharp and readable; at most
two translucent, softly blurred covers sit behind it in an isolated perspective
stack. Hover or keyboard focus spreads the cards toward the bottom left, with
the front cover springing furthest outward in three dimensions. Animate only the
individual covers; the backing and thumbnail wrapper must not scale, translate or
change bounds. Keep the backing transparent and the thumbnail host
unclipped; use the `uikit-collection-icon--preview-stack` modifier in collection
tiles. The fan extends beyond the resting footprint and stops for reduced motion. A single cover stays
flat. This depth communicates a collection, not an extra modal or independent
set of actions; navigation and the accessible name belong to one surrounding
link or button.
